## PG API

현재 PG API는 **v2**를 사용하고 있습니다.

- PG사: example-pg
- API 버전: v2
- 인증: API key

## 환불 상태

환불 상태 코드:

- `REQUESTED` — 환불 요청
- `DONE` — 환불 완료

> 부분환불은 현재 미지원 상태입니다.

## 환불 정책

- 환불 가능 기간: 결제 후 **7일**
- 부분환불: **미지원**

## 결제 유형별 정책

- 일반 결제: 표준 정책 적용
- 정기결제: 표준 정책 적용
- 해외결제: 별도 정책 없음 (아직 정의되지 않음)
